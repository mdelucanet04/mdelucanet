# Portale sostenibilità Gruppo ZONIN

Template HTML e CSS responsive per la divulgazione delle attività di sostenibilità
e il download dei report aziendali.

## Struttura

- `index.html`: struttura della pagina
- `style.css`: grafica e layout responsive
- `report/`: cartella in cui inserire i PDF

## Inserimento dei report

Creare una cartella denominata `report` e inserire i file PDF con questi nomi:

- `report-sostenibilita-2025.pdf`
- `report-sostenibilita-2024.pdf`
- `report-sostenibilita-2023.pdf`

In alternativa, modificare gli attributi `href` nella sezione "Report di sostenibilità".

## Pubblicazione con GitHub Pages

1. Creare un nuovo repository GitHub.
2. Caricare `index.html`, `style.css` e la cartella `report`.
3. Aprire **Settings > Pages**.
4. Selezionare **Deploy from a branch**.
5. Scegliere il branch `main` e la cartella `/root`.
6. Salvare.

Il sito sarà pubblicato a un indirizzo simile a:

`https://nomeutente.github.io/nome-repository/`

## Personalizzazione

Prima della pubblicazione:

- sostituire i dati ESG dimostrativi;
- verificare testi, marchi e denominazioni ufficiali;
- inserire i report PDF reali;
- sostituire l'indirizzo e-mail dimostrativo;
- aggiornare privacy policy e documenti societari;
- usare immagini autorizzate o di proprietà dell'impresa.
